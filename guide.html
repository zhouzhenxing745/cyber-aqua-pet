方法一 · 添加到主屏幕（PWA）

RECOMMENDED

应用已内置 Service Worker 离线缓存与全套主屏幕图标。装好后是独立图标、全屏无地址栏、飞行模式可玩，体验与原生 App 一致，且永久有效、不用每 7 天重签。唯一前提：一个 https:// 网址。

iPhone / iPad · Safari 一个 https 网址（下面第 1 步免费获得） 不需要 Mac · 不需要 Apple 开发者账号
本方法进度0/6
本项目永久网址已部署：https://zhouzhenxing745.github.io/cyber-aqua-pet/ —— 用 iPhone Safari 打开它即可直接从第 2 步开始；第 1 步只在你想部署到自己账号时才需要。
STEP 1获得一个 https 网址（二选一）

临时体验（30 秒、免账号）：电脑先运行 npm run serve，再开一个终端执行下面的命令，把本机鱼缸变成公网 https 网址：

TERMINAL · 临时隧道
npx --yes cloudflared tunnel --url http://127.0.0.1:8765
# 输出里找 https://xxxx.trycloudflare.com ，手机 Safari 打开它

长期固定（免费托管）：把 www/ 文件夹里的全部内容上传到 GitHub 仓库 → Settings ▸ Pages → Source 选 Deploy from a branch、分支 main、目录 / (root) → Save，一分钟后得到 https://用户名.github.io/仓库名/。也可把 www 文件夹拖到 Netlify / Cloudflare Pages / Vercel 任一免费静态托管。

局域网 http 地址不行：http://192.168.x.x:8765 只能在线玩，iOS 不允许 http 页面添加主屏幕或离线缓存。必须是 https。
STEP 2用 iPhone 的 Safari 打开网址

必须是 Safari。Chrome、Edge、微信 / QQ 内置浏览器都没有“添加到主屏幕”能力。地址栏出现小锁图标才说明 https 生效。

确认页会显示图标与名称（水族宠物机）。点右上角添加后回到主屏幕，最后一页就能看到新图标。

STEP 5点图标启动，轻触进入鱼缸

启动后是全屏深海画面（无地址栏）。轻触“轻触进入鱼缸”解锁声音并开始。操作：单指拖动旋转视角、双指捏合 / 滚轮缩放、底部喂食后按住倾倒撒饲料、右侧控制台 18 项实时调节。

STEP 6验证离线与存档

开飞行模式再点图标：应能正常进入（Service Worker 已缓存全部资源）。喂鱼、清洁、客人邀请等进度保存在本机，关掉再开不会丢。

以后代码更新后，联网打开一次即自动拉取新版本（network-first 缓存策略），无需重新添加图标。

方法二 · 没有 Mac？云端编译 IPA

CLOUD BUILD + SIDELOAD

Apple 规定 iOS 包必须在 macOS 上编译签名——但那台 Mac 可以是 GitHub 的免费云主机。项目已附带工作流 .github/workflows/ios-build.yml：push 后自动产出未签名 .ipa，再用电脑上的侧载工具以你的 Apple ID 重签安装。

GitHub 账号（免费） Windows / Mac 电脑 + 数据线 Apple ID（免费即可） 每 7 天重签一次
本方法进度0/6
STEP 1把项目推送到 GitHub

在 GitHub 新建一个空仓库（不要勾选 README），然后在项目根目录（D:\鱼缸程序）执行：

TERMINAL · 推送
git init
git add .
git commit -m "cyber aqua pet"
git branch -M main
git remote add origin https://github.com/你的用户名/cyber-aqua.git
git push -u origin main

仓库里必须包含 .github/workflows/ios-build.yml、www/、tools/build-ios.sh、package.json、capacitor.config.json。

STEP 2触发云编译

push 会自动触发。也可手动：仓库页 Actions 标签 → 左侧 iOS Build → Run workflow → 选 main → 绿色 Run 按钮。

STEP 3下载 IPA 产物

等约 5–8 分钟运行变绿 → 点进该 run → 页面底部 Artifacts → 下载 CyberAqua-unsigned-ipa 压缩包 → 解压得到 CyberAqua-unsigned.ipa。

这是未签名包，双击 / 爱思助手“直装”都装不上——必须经下一步用你的 Apple ID 重签。任何宣称“免签直装 ipa”的渠道都不可信。
STEP 4电脑装 Sideloadly，连接 iPhone

到 sideloadly.io 下载 Windows / macOS 版并安装打开。iPhone 用数据线连电脑，手机弹窗点“信任此电脑”并输入锁屏密码。（备选：AltStore + AltServer，可在同 Wi-Fi 下自动续签。）

STEP 5拖入 IPA → 输入 Apple ID → Start

Sideloadly 识别到设备后，把 .ipa 拖进窗口，填你的 Apple ID（免费账号即可，建议用小号），点 Start。期间可能要求输入 Apple ID 密码 / 双重验证码，按提示填写，等待进度走完。

STEP 6iPhone 信任证书并启动

手机：设置 ▸ 通用 ▸ VPN与设备管理 → 点你的 Apple ID 开发者证书 → 信任。回桌面点“水族宠物机”即可运行。

免费 Apple ID 签名 7 天有效：到期 App 会闪退 / 打不开，用 Sideloadly 再 Start 一次即续期（缸内进度保留）。想彻底摆脱重签：用方法一 PWA，或方法三的付费开发者账号。

方法三 · 有 Mac：Xcode 原生签名

NATIVE / TESTFLIGHT

最稳的路线：Capacitor 工程已配置好（com.cyberaqua.pet / 应用名“水族宠物机” / 启动图背景 #030d15）。免费 Apple ID 可直接真机运行；付费账号可上 TestFlight / App Store，不再受 7 天限制。

macOS 12+ · Xcode 15+ Node.js 18+ Apple ID（免费可跑真机） iOS 16+ 需开开发者模式
本方法进度0/5
STEP 1装好 Xcode 与命令行工具

App Store 安装 Xcode，首次启动同意许可；终端执行：

TERMINAL · macOS
xcode-select --install
sudo xcodebuild -license accept
STEP 2同步工程（两种走法）

走法 A（推荐，直接真机）：生成并打开 Xcode 工程，跳到第 3 步签名后 ⌘R。

TERMINAL · 工程
cd /path/to/鱼缸程序
npm install
npm run ios:open   # 自动 cap add ios + sync + 打开 Xcode

走法 B（要 .ipa 文件）：一条命令产出未签名包，供侧载或留档：

TERMINAL · 打包
npm run ios:build  # → build/CyberAqua-unsigned.ipa
脚本会自动写入 1024px 应用图标、执行无签名 archive 并 zip 成 Payload 结构；签名安装请走走法 A。
STEP 3Signing & Capabilities 选你的 Team

Xcode 左侧选 App 工程 → TARGETS App → Signing & Capabilities：勾 Automatically manage signing，Team 选你的 Apple ID（显示为 Personal Team），把 Bundle Identifier 改成全网唯一串。对照下图：

STEP 4开开发者模式，选设备 ⌘R

iPhone（iOS 16+）：设置 ▸ 隐私与安全性 ▸ 开发者模式 → 打开 → 按提示重启。数据线连 Mac（或 Xcode ▸ Window ▸ Devices and Simulators 里同 Wi-Fi 配对），Xcode 顶部运行目标选你的 iPhone，按 ⌘R 编译安装。

STEP 5信任证书 → 启动；进阶上架

首次启动若提示“未受信任的开发者”：设置 ▸ 通用 ▸ VPN与设备管理 → 信任你的证书，再点桌面图标。

付费开发者账号（$99/年）：Product ▸ Archive → Organizer 里 Distribute App → TestFlight（邀请测试、90 天有效）或 App Store（审核上架、永久有效）。

常见问题排查

装不上 / 打不开 / 没声音，先对照这里。

三个条件缺一不可：Safari 浏览器（微信 / Chrome 不行）、https 网址（http 不行）、非无痕浏览（无痕窗口不允许添加）。菜单较长，记得往下滑；iPad 上分享按钮在顶部。
首次启动需要联网加载。确认托管目录包含 www 的全部文件（尤其 vendor/three.module.js、sw.js、icons/）。仍白屏：Safari 设置里清除该网站数据后重开；云编译包白屏多为侧载未完成信任步骤。
iOS 要求用户手势解锁音频：启动时轻触“轻触进入鱼缸”即解锁。右上角喇叭按钮是总静音开关；请调媒体音量（不是铃声音量），并确认侧边静音键未拨下（部分机型影响外放）。
饱食 / 心情 / 鱼缸配置等存于本机 localStorage，正常关开不丢。清除 Safari 网站数据、删除主屏幕图标、应用内“重新养一缸鱼”会重置。暂无云同步，换机需重新养。
右侧控制台把画质切到“低”（降分辨率与粒子），关闭光柱与网格；视角预设选“正面”减少 overdraw。PWA 与原生壳性能相同，瓶颈在 GPU 而非安装方式。
依次检查：① 证书已在 VPN与设备管理 里信任；② 免费签名是否超过 7 天（重签即可）；③ Bundle ID 与设备上已有 App 冲突（改唯一）；④ 数据线 / 信任电脑弹窗是否完成。AltStore 用户确认 AltServer 在同网络运行。
支持任意方向，横屏更沉浸；已适配 viewport-fit=cover 安全区，刘海与 Home 条不会遮挡控制台和按钮。PWA 为 standalone 全屏，无地址栏。
